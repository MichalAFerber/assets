# Favicons

Brand favicons for the estate's sites (TGWAB products, identity sites, MyKK, LAN
intranet, and fully managed client sites). Per DS §11 the SVG favicon *is* the brand icon;
`<domain>-512.png` is the site's `icon-512.png` where one ships, otherwise rendered from
the SVG at 512×512 (noted). `.ico` files are deliberately omitted. Collected 2026-08-23.
